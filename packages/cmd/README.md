# Cmd

[![](https://data.jsdelivr.com/v1/package/npm/@jlbyte/cmd/badge)](https://www.jsdelivr.com/package/npm/@jlbyte/cmd)

Wrapper of `cac`.

## Usage

- Install

```bash
npm -i @jlbyte/cmd --prefer-offline
```

- Instance

```js
import Cmd from '@jlbyte/cmd';

const cli = new Cmd('cli');
```

See cac [docs](https://github.com/cacjs/cac) for usage.
