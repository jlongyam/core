# Cmd

Command line interface generator

## Design

Help design

```sh

cli v1.0.0
  App description ...
  Syntax:
  - <any> is require
  - [any] is optional
  - --any is option
  - -a is option alias
   
Usage:
  $ cli <command> [arguments] [options]

Commands:
  help [command]             display help for command

Arguments:
  [...args]                  arguments or sub command

Options:
  -h, --help                 display help for command
  
Examples:
  $ cli help

Links:
  - <https://example.com>

```
